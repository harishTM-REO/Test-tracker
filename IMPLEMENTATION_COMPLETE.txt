HOW IT WORKS:
──────────────────────────────────────────────────────────────────────────────

Simple Logic:
  if (child is also a parent) {
    REMOVE from parent's children
  } else {
    KEEP in parent's children
  }

Example:
  /brand/adidas is a separate parent? YES → REMOVE from /brand's children
  /brand/birkenstock is NOT a parent? NO → KEEP in /brand's children

FEATURES COMBINED:
──────────────────────────────────────────────────────────────────────────────

1. Trailing Slash Deduplication
   - Removes /brand/adidas vs /brand/adidas/ duplicates
   
2. Redundancy Filter
   - Keeps/removes parents based on children
   
3. Children Deduplication ← NEW!
   - Removes children that are separate parents

All THREE features work automatically together!
